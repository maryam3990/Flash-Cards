# SAVEME

A minimalist flashcard app in plain HTML, CSS and JavaScript. No build step, no dependencies.

## Features

- Subjects as folders, each with its own color
- Study mode: flip cards, move one by one, jump to any card, shuffle
- All cards mode: grid view with search and show/hide answers
- Adjustable card text size
- Cards are saved in your browser with localStorage
- Light and dark brown themes that follow your device setting

## Run it

Open `index.html` in a browser. That is all.

## Host it on GitHub Pages

1. Push these files to a GitHub repository.
2. Go to Settings, then Pages.
3. Under Build and deployment, choose "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/` after a minute or so.

## Notes

Cards are stored per browser and per device. Clearing site data erases them.
